## 2. Solution Architecture

### 2.1 Core Implementation Strategy
The solution implements a **three-layer approach**:

2. **Syntax Highlighting Layer**: VS Code-style Dart/Flutter highlighting  
3. **Modal Display Layer**: Clean, responsive code inspection interface

### 2.2 Technical Design Decisions

#### HTML Escaping Strategy
```javascript
// Correct escaping order implemented:
.replace(/&/g, '&amp;')     // 1. Ampersands FIRST (prevents double-escaping)
.replace(/</g, '&lt;')      // 2. Less-than tags  
.replace(/>/g, '&gt;')      // 3. Greater-than tags
```

**Rationale**: Processing ampersands first prevents corruption of already-escaped content.

#### Syntax Highlighting Approach
```javascript
// Sequential regex pattern matching:
1. Numbers (highest specificity)
2. Keywords (Dart language tokens)
3. Types & Classes (Flutter/Dart types)
4. Strings (quoted content)
5. Comments (single-line //)
6. Methods & Functions
7. Properties (post-dot access)
```

**Rationale**: Order prevents pattern collision and ensures accurate highlighting.

  // ... followed by syntax highlighting
