# Flutter Casino Demo - Integration Test Suite

## 🎯 Overview

Comprehensive integration test suite designed to validate all 16 automation keys across the Flutter Casino Demo application. Generated by the Flutter KeyCheck Orchestrator for enterprise-grade automation validation.

## 🚀 Quick Start

### Prerequisites
```bash
# Add integration_test dependency to pubspec.yaml
flutter pub add integration_test --dev

# Ensure flutter_test is available
flutter pub add flutter_test --dev
```

### Running Tests

#### Full Test Suite
```bash
# Run complete validation suite
flutter test integration_test/casino_automation_test.dart

# Run with verbose output  
flutter test integration_test/casino_automation_test.dart --reporter expanded

# Run on specific device
flutter test integration_test/casino_automation_test.dart -d chrome
```

#### Individual Test Groups
```bash  
# Run only critical keys validation
flutter test integration_test/casino_automation_test.dart --name "Critical Keys Validation"

# Run only betting system tests
flutter test integration_test/casino_automation_test.dart --name "Betting System Validation"

# Run only state management tests
flutter test integration_test/casino_automation_test.dart --name "Game State Management"
```

## 🚨 Troubleshooting

### Common Issues

#### Test Timeout
```bash
# Increase timeout for slow devices
flutter test integration_test/ --timeout 120s
```

#### Animation Issues  
```dart
// Wait for animations to complete
await tester.pumpAndSettle(const Duration(seconds: 3));

// Skip animations in tests
await tester.binding.setSurfaceSize(const Size(800, 600));
```

#### Key Not Found
```dart
// Debug key presence
print('Available keys: ${tester.allWidgets.where((w) => w.key != null)}');

// Wait for widget to appear
await tester.waitFor(find.byKey(const Key('targetKey')), timeout: Duration(seconds: 5));
```

### Validation Failures

#### Critical Key Missing
- **Impact**: Test suite will fail immediately
- **Action**: Check widget implementation for key assignment
- **Debug**: Use Flutter Inspector to verify key presence

#### Animation Not Completing
- **Impact**: Timeouts in game modules
- **Action**: Increase `pumpAndSettle` duration
- **Debug**: Check for infinite animations or loops

#### State Management Issues
- **Impact**: Inconsistent test results
- **Action**: Add state reset between tests
- **Debug**: Verify proper cleanup in `tearDown` methods
